# CodeAlpha Calculator

A responsive calculator built with HTML, CSS and JavaScript as part of my CodeAlpha Frontend Development internship.

## Features
- Addition, subtraction, multiplication and division
- Clear (AC) and delete (DEL)
- Real-time display of the current and previous number
- Keyboard support
- Dark mode design with a mint green accent
- Responsive layout for phones and desktops

## Tech Used
HTML, CSS, JavaScript

## How to Run
Open `index.html` in your browser.
